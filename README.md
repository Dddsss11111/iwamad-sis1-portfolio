# Personal Portfolio — Doszhan Bakytuly

* **Live Pages URL:** https://dddsss11111.github.io/iwamad-sis1-portfolio/
* **About the site:** This professional single-page personal portfolio is built by an IT Management student at KBTU. It showcases academic background, technical skills, and real university project repositories including React, Python, and iOS development. The interface features an interactive theme switcher and a robust form validation mechanism.

### Design Decisions:
1. **Responsive Structure:** Implemented a modern layout that gracefully adapts from a clean single-column mobile view (375px) to an expanded grid layout on desktop (1200px) with zero horizontal scrolling.
2. **Cohesive Design System:** Utilized Tailwind CSS styling combined with custom CSS variables to establish a consistent visual hierarchy, typography scale, and seamless light/dark mode adaptation.
3. **Accessibility & Usability:** Ensured high accessibility standards by including explicit keyboard focus states (`focus-visible`), proper HTML semantics, and precise distinct form error messages.
